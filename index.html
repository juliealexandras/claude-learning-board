What this is

A learning plan for working better with Claude as a designer, design engineer, and studio owner. Each card is one course, experiment, or habit. Cards start in a suggested order, top to bottom.

How to use it

  • Drag a card to another column, or use the arrow buttons on any device.
  • Open Notes on a card to record what you learned and the prompts that worked. Select Save notes when you finish.
  • Use + Add card in any column to add your own item. New cards default to Misc, so it's a quick way to suggest a useful link.
  • Use the chips above the board to focus on one track.
  • Remove a card from its Notes panel.

The five tracks

  • Claude Academy: free official courses and Anthropic's prompting guides.
  • Claude Design: prototypes, explorations, and design system use.
  • Code + Figma: Claude Code with the Figma plugin, both directions.
  • Habits: everyday practices that improve results.
  • Misc: extra references and suggestions from anyone using the board, such as an article, video, tool, or template.

Good to know

  • Progress saves in this browser only. Clearing site data or switching browsers or devices starts a fresh board.
  • The starting cards live in cards.js. Edit that file to change the plan, then select Reset board to load it.
  • Ask Claude to review your board anytime for a suggestion on what to do next.
