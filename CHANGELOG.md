# Changelog

## v1.4.0 (2026-10-16)

- Renamed boards: Up next is now To do, and In progress is now Doing
- New row view, the default: each board is a row and its cards scroll sideways, which reads better on phones
- Rows and Columns toggle above the board, remembered per browser

## v1.3.0 (2026-10-16)

- Replaced the floppy disk cards with clean rounded cards: track chip, two-line description, and a footer with the link, Notes, and Move
- Links are highlighted, underlined text with an external link icon
- Soft rounded corners on boards, panels, chips, and controls
- Progress shows in a compact pill, and each board header has its own + button
- Notes open from an icon and save as you type, in Verdana

## v1.2.0 (2026-10-16)

- Simpler disks: one Move menu replaces the move, DNF, notes, and remove buttons
- Notes are typed straight into the disk's black band, in Verdana, and save as you type
- The link moves into the label's top line, and titles look handwritten in marker
- Shorter Read me, with color blocks instead of bullets for tracks
- Removed the indigo frame around the page

## v1.1.0 (2026-10-16)

- 90s floppy disk redesign: each card is a disk with a shutter, paper label, and holographic link strip
- New palette from 90s product mockups: charcoal sheet in an indigo frame, with orchid, periwinkle, coral, holo mint, and holo pink tracks
- New type: Futura PT with Jost as the fallback, Anton for board titles, and Space Mono for captions
- State on the disk: a lit shutter for In progress, a stamp for Done, and a ripped label for Did not finish
- Boards show six disks, then scroll with a range counter
- Dark only

## v1.0.0 (2026-10-16)

First public release.

- Kanban board with Up next, In progress, Done, and Did not finish columns
- 23 starting cards across Claude Academy, Claude Design, Code + Figma, and Habits, plus a Misc track for suggestions
- Notes, track filters, add and remove cards, and DNF reasons
- Progress saves in the browser, with export and import
- New cards from `cards.js` merge into existing boards without losing progress
- Link freshness dates on cards
- Issue forms, contributing guide, card validator, and a weekly link check
- Light and dark mode, phone layout
